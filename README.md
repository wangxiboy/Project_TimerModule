

## 一、实现效果

1. 使用 STM32F103 的 TIM3 定时器，以**计数方式**（更新中断）控制 LED 以 2s 频率周期性地亮—灭。
2. 使用 TIM3 的**PWM 模式**，让 LED 以呼吸灯方式渐亮渐灭，周期为 1~2 秒，自行调整占空比变化达到满意效果。

---


## 二、配置过程

### 实验一：定时器计数模式，2s 周期 LED 亮灭

**原理**：利用 TIM3 更新中断定时 1s，在中断里翻转 PA6，实现亮 1s、灭 1s，完整周期 2s。

#### CubeMX 配置


| 配置项    | 设置值                                                       | 说明             |
| --------- | ------------------------------------------------------------ | ---------------- |
| RCC       | HSE Crystal/Ceramic                                          | 外部 8MHz 晶振   |
| 时钟树    | SYSCLK=72MHz（HSE×9），APB1=/2                               | 定时器时钟=72MHz |
| PA6       | GPIO_Output，推挽，初始电平 Low                              | 普通输出驱动 LED |
| TIM3      | Activated，内部时钟                                          | 启用定时器       |
| TIM3 参数 | PSC=7199，Counter Mode=Up，ARR=9999，auto-reload preload=Enable | 定时 1s          |
| NVIC      | TIM3 global interrupt 勾选                                   | 使能更新中断     |

**定时计算**：

```
计数频率 = 72MHz / (7199+1) = 10kHz
溢出周期 = 10000 / (9999+1)  = 1s     // 每 1s 溢出一次，触发更新中断
```

**现象**：每次更新中断翻转一次 PA6，LED 亮 1s、灭 1s，循环往复，完整周期 2s。

---

### 实验二：定时器 PWM 模式，呼吸灯

**原理**：将 PA6 配置为 TIM3_CH1 复用输出，启动 PWM 输出，在软件中缓慢改变 CCR（占空比）实现渐亮渐灭。

#### CubeMX 配置

| 配置项    | 设置值                                                       | 说明                |
| --------- | ------------------------------------------------------------ | ------------------- |
| RCC       | HSE Crystal/Ceramic                                          | 外部 8MHz 晶振      |
| 时钟树    | SYSCLK=72MHz（HSE×9），APB1=/2                               | 定时器时钟=72MHz    |
| PA6       | **TIM3_CH1**，复用功能推挽（AF Push-Pull），速度 High        | 定时器 PWM 复用输出 |
| TIM3      | Activated，内部时钟                                          | 启用定时器          |
| TIM3 Mode | Channel1 = PWM Generation CH1                                | PWM 输出模式        |
| TIM3 参数 | PSC=71，Counter Mode=Up，ARR=999，auto-reload preload=Enable | PWM 频率 1kHz       |
| PWM CH1   | Pulse(CCR)=0，PWM mode 1                                     | 初始占空比 0%       |

**PWM 频率计算**：

```
计数频率 = 72MHz / (71+1) = 1MHz
PWM 频率 = 1MHz / (999+1) = 1kHz   // 周期 1ms，LED 不闪烁
占空比   = CCR / 999               // CCR 0~999 对应 0%~100%
```


**现象**：LED 在约 2s 内由暗渐亮，再由亮渐暗，循环往复，实现呼吸灯效果。调整 `HAL_Delay` 的延时或 CCR 步进，即可改变呼吸周期（1~2s）。

### PWM 波形观察与分析（Keil 逻辑分析仪）


为观察 PWM 输出波形，使用 Keil 调试器的逻辑分析仪（Logic Analyzer）添加 PA6 引脚信号。由于 Logic Analyzer 直接输入寄存器位表达式即可提取引脚电平，所添加的信号表达式为：

```
(PORTA & 0x00000040) >> 6
```

其中 `0x00000040` 为 PA6 对应的位掩码（bit6），`>> 6` 将该位右移到最低位，从而得到 PA6 引脚的电平（0 或 1），Display Type 设为 Bit。



观察结果分析：

1. **波形形态**：PA6 输出为稳定、规则的 PWM 方波，高/低电平跳变清晰，证明 TIM3_CH1 的 PWM 硬件输出正常，引脚复用配置正确。
2. **周期/频率**：方波周期约为 1ms，与设计 PWM 频率（1kHz）一致，验证了 PSC=71、ARR=999 的配置计算正确。
3. **占空比变化**：方波的高电平时间占比即占空比（占空比 = CCR / ARR）。观察可见，随着呼吸过程，方波高电平宽度逐渐变宽（渐亮段，CCR 增大、占空比增大），再逐渐变窄（渐灭段，CCR 减小、占空比减小），占空比在 0%~100% 之间循环，直观体现了"渐亮渐灭"的实现原理。

> 说明：精确读取某一时刻的占空比数值，可用逻辑分析仪的游标测量高电平宽度与周期，占空比 = 高电平时间 ÷ 周期 × 100%。

## 三、原理说明

### （一）STM32 定时器原理

STM32F103 内部的通用定时器（TIM2~TIM5）本质上是一个**可编程计数器**，通过对输入时钟进行分频并计数，在设定的时间间隔产生更新事件，从而实现定时功能。其核心组成包括：

- **计数器 CNT**：实时记录当前计数值。支持向上计数（从 0 计到 ARR）、向下计数、中心对齐计数三种模式。
- **预分频器 PSC**：对定时器输入时钟进行分频，分频系数为 `PSC+1`，决定计数一次所需时间。
- **自动重装载寄存器 ARR**：计数目标值。CNT 计数到 ARR 后清零并产生**更新事件（Update Event）**。
- **捕获/比较寄存器 CCR**：用于与 CNT 比较，是 PWM 模式和输入捕获的基础。

**时钟来源与分频关系**：TIM2~TIM5 挂载在 APB1 总线上。当 APB1 预分频系数不等于 1 时，定时器时钟 = APB1 总线时钟 × 2。本实验中系统时钟 72MHz、APB1 分频为 /2，故定时器实际输入时钟为 72MHz。

**核心计算公式**：

```
计数频率   = 定时器时钟 / (PSC + 1)
溢出周期   = 计数频率 / (ARR + 1) = 定时器时钟 / [(PSC+1) × (ARR+1)]
```

当 CNT 计数到 ARR 溢出时产生更新事件，若使能中断，则触发**更新中断**，可在中断服务函数中执行定时任务（如翻转 LED）。

### （二）脉宽调制（PWM）生成方法

**PWM（Pulse Width Modulation，脉宽调制）** 是定时器**输出比较功能**下的一种工作模式，并非独立硬件模块。其原理是：定时器在输出比较通道上，将 CNT 与 CCR 不断比较，根据比较结果在引脚上输出高低电平，从而**由硬件自动生成一个频率固定、占空比可调的方波**。

**PWM 模式 1（向上计数）输出规则**：

```
CNT < CCR  →  引脚输出有效电平（高电平）
CNT ≥ CCR  →  引脚输出无效电平（低电平）
```

**占空比计算公式**：

```
占空比 = CCR / ARR
```

- ARR 决定 PWM 波的**频率（周期）**；
- CCR 决定 PWM 波的**占空比**，修改 CCR 即可实时改变占空比。

**引脚复用**：要使定时器 PWM 输出，须将对应 GPIO 引脚配置为**复用功能推挽输出（Alternate Function Push-Pull）**，此时引脚电平由定时器硬件自动控制，无需 CPU 频繁翻转 IO。TIM3_CH1 对应引脚为 PA6。

**PWM 调光的物理含义**：LED 亮度取决于平均电流，而**平均电压 = 峰值电压 × 占空比**。占空比越大，LED 平均电流越大、越亮。因此通过软件缓慢改变 CCR（占空比），即可实现 LED 的渐亮渐灭（呼吸灯）效果。
